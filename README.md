# 弈境 · 中国象棋

使用 Bun、React、TypeScript 与 Tailwind CSS 构建的现代中国象棋游戏。

## 功能

- 完整象棋走法、蹩马腿、塞象眼、炮架、九宫、将帅照面等规则校验
- 将军、绝杀、困毙、认输与对局计时
- 人机对弈与本地双人模式
- 入门 / 棋手 / 大师三档 AI，Web Worker 后台推演
- 悔棋、棋盘翻转、着法记录、吃子统计与音效反馈
- 夜阑木韵、青瓷云岚、水墨长卷、霓虹残局四套完整视觉主题
- 桌面及移动端响应式界面

## 运行

```bash
bun install
bun run dev
```

生产构建：

```bash
bun run build
bun run preview
```
